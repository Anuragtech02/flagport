How it works

An afternoon,
not a quarter.

Every other alternative asks you to swap SDKs and rewrite each flag check. Flagport asks for a config change.

01

Import

Give Flagport a read-only LaunchDarkly API token. It copies the flags, targeting rules and segments of the environment you pick.

02

Repoint

Add baseUri, streamUri and eventsUri to your SDK config and swap the SDK key. Nothing else in your code moves.

03

Ship

Toggle flags in the Flagport dashboard. Your apps get each change over the streaming connection the SDK already keeps open.

ReversibleChanged your mind? Delete the three lines and you are back on LaunchDarkly.

FAQ

Fair questions.

Is Flagport affiliated with LaunchDarkly?

No. Flagport is an independent open-source project. Your apps keep using LaunchDarkly's open-source SDKs; Flagport is a different server for them to talk to.

Do I have to change my code?

Only your SDK configuration: three URLs and the SDK key. Flag checks, contexts and targeting stay as they are.

What happens to my flags in LaunchDarkly?

Nothing. The import only reads from your account. You can run both side by side while you test.

What does not work yet?

Experimentation, secure mode, big segments and the newer data saving mode. Mobile SDKs have not been tested on real devices, and the importer has not been run against a live LaunchDarkly account.

Can I host it myself?

Yes. It is one Cloudflare Worker: clone the repository, deploy, set an admin token. Sign-ups are off unless you turn them on.

Is it really open source?

Yes, under the MIT licence. The repository holds everything this site runs, including the tests.

What is the hosted server?

The same code, run by the author on Cloudflare and open for anyone to create a workspace. It has no billing, no support contract and no uptime guarantee. For anything you depend on, self-host.

What if I lose my workspace key?

It cannot be recovered. There are no accounts or emails, and the server keeps only a hash of the key. Your SDK keys keep working, but you can no longer change flags, so store the key in a password manager.
